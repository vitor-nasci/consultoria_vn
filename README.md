# Consultoria VN - Gerenciamento de Alunos

Aplicativo desktop desenvolvido em Python e Flet para cadastro e gestão de alunos de consultoria esportiva.

## Funcionalidades
- Cadastro de alunos com validação de campos.
- Listagem dos alunos cadastrados.
- Edição dos dados e exclusão de registros.
- Persistência dos dados em arquivo JSON.
